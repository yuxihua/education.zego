# 教培直播系统 - 完整部署指南

> 前后端完整部署，从零到上线

---

## 一、环境要求

| 组件 | 版本 | 用途 |
|------|------|------|
| Node.js | >= 18 | 前后端运行环境 |
| MySQL | >= 8 | 主数据库 |
| Redis | >= 6 | 缓存/会话 |
| npm | >= 9 | 包管理 |

## 二、快速开始（5分钟）

```bash
# 1. 解压项目
unzip edu-live-full.zip
cd edu-live-full

# 2. 部署后端
cd edu-live-server
npm install
cp .env.example .env
# 编辑 .env 填入你的数据库/支付/BBB 等配置
npm run dev        # 开发模式启动（端口 8080）

# 3. 部署前端（另开终端）
cd ../edu-live-admin
npm install
npm run dev        # 开发模式启动（端口 3000）
```

访问前端：`http://localhost:3000`
访问后端：`http://localhost:8080/api/health`

## 三、生产部署（PM2 方式）

### 3.1 后端部署

```bash
cd edu-live-server

# 安装生产依赖
npm ci --only=production

# 配置环境变量
cp .env.example .env
vim .env   # 填入所有配置项

# 创建必要目录
mkdir -p logs uploads

# 同步数据库
npm run db:sync

# PM2 启动
pm2 start ecosystem.config.js --env production
pm2 save
pm2 startup
```

### 3.2 前端部署

```bash
cd edu-live-admin

# 安装依赖
npm ci --only=production

# 构建生产包
npm run build

# 构建产物在 dist/ 目录，用 Nginx 托管
```

### 3.3 Nginx 配置

```bash
# 复制配置
sudo cp edu-live-server/nginx.conf /etc/nginx/conf.d/edu-live.conf

# 修改配置中的域名和证书路径
sudo vim /etc/nginx/conf.d/edu-live.conf

# 测试并重载
sudo nginx -t
sudo systemctl reload nginx
```

## 七、常见问题

| 问题 | 解决 |
|------|------|
| 端口占用 | `lsof -i :8080` 找到进程并 kill |
| 数据库连接失败 | 检查 .env 中 DB_HOST/DB_PASSWORD |
| 支付回调不触发 | 确认 BASE_URL 是外网可访问的域名 |
| BBB 入会失败 | 检查 BBB_API_BASE_URL 和 BBB_SHARED_SECRET |
| 前端跨域 | 确认 vite.config.js 中 proxy 配置正确 |

### 访问域名显示 JSON：`{"message":"接口不存在"}`

这是 Nginx 将 `/` 也反代到后端导致的。后端只处理 API，请求首页会走 404 返回 JSON。

正确做法：

```nginx
location / {
	try_files $uri $uri/ /index.html;
}

location /api/ {
	proxy_pass http://127.0.0.1:8080;
}
```

如果你使用同域部署（例如 `iot.hualongda.com.cn`），可直接使用：

- `edu-live-server/docs/nginx-iot.hualongda.com.cn.conf`

## 八、BBB 联调验收清单

按顺序执行，全部通过表示 BBB 主流程可用：

1. 创建直播间

- 后台进入“直播管理”，创建一条直播间。

2. 老师入会（主持人）

- 进入“老师端直播”页面，点击“主持人入会”。
- 预期：可打开 BBB 页面，且后端直播状态变为 `living`。

3. 助教入会（听众）

- 助教从直播管理进入老师端页面（听众模式）。
- 预期：按钮显示“听众入会”，不会触发创建会议，仅进入课堂。

4. 学员入会

- 学员端进入课程直播间并点击“进入课堂”。
- 预期：已购学员可进入；未购学员被拒绝（免费课程除外）。

5. 结束会议

- 老师端点击“结束会议”。
- 预期：BBB 会议结束，直播状态变为 `finished`。

6. 回放生成

- 在直播详情页点击“刷新回放状态”。
- 预期：生成后展示回放地址，可“查看回放/复制回放地址”。

7. 权限校验

- 非本机构账号访问直播回放接口。
- 预期：返回 403，无越权数据泄露。

## 九、Windows 联调命令（推荐）

如果在 Windows PowerShell 遇到执行策略拦截 `npm.ps1`，请统一使用 `npm.cmd`。

1. 前端构建校验

```powershell
cd edu-live-admin
npm.cmd run build
```

- 通过标准：命令退出码为 0，产物生成在 `dist/` 目录。

2. BBB 路由快速加载校验

```powershell
cd ..\edu-live-server
node -e "require('./routes/bbb'); console.log('bbb-route-ok')"
```

- 通过标准：输出 `bbb-route-ok`，且进程正常退出。

3. Redis 噪音日志说明

- 若终端持续出现 `[Redis] 连接错误`，通常是本地 Redis 未启动或连接参数错误。
- 该日志会干扰联调输出，建议先修复 Redis 再执行验收命令。

4. 验收记录模板


## 十、上服务器实操步骤（Ubuntu 22.04）

以下步骤适用于单台 Linux 服务器部署（前后端同机）。

### 10.1 服务器准备

```bash
# 1) 更新系统
sudo apt update && sudo apt upgrade -y

# 2) 安装基础工具
sudo apt install -y git curl nginx redis-server

# 3) 安装 Node.js 18（官方源）
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# 4) 安装 PM2
sudo npm install -g pm2

# 5) 检查版本
node -v
npm -v
pm2 -v
```

### 10.2 上传项目到服务器

方式 A：使用 git（推荐）

```bash
cd /opt
sudo mkdir -p edu-live
sudo chown -R $USER:$USER /opt/edu-live
cd /opt/edu-live

# 替换为你的仓库地址
git clone <你的仓库地址> edu-live-bbb-full
cd edu-live-bbb-full
```

方式 B：本地打包上传

```bash
# 本地执行
zip -r edu-live-bbb-full.zip edu-live-bbb-full

# 上传到服务器后执行
cd /opt/edu-live
unzip edu-live-bbb-full.zip
cd edu-live-bbb-full
```

### 10.3 部署后端（edu-live-server）

```bash
cd /opt/edu-live/edu-live-bbb-full/edu-live-server

# 安装依赖（生产）
npm ci --only=production

# 环境变量
cp .env.example .env
vim .env

# 创建目录
mkdir -p logs uploads

# 数据库初始化（按项目命令执行）
npm run db:sync

# 使用 PM2 启动
pm2 start ecosystem.config.js --env production
pm2 save
pm2 startup
```

后端健康检查：

```bash
curl http://127.0.0.1:8080/api/health
```

### 10.4 部署前端（edu-live-admin）

```bash
cd /opt/edu-live/edu-live-bbb-full/edu-live-admin

# 安装依赖并构建
npm ci
npm run build

# 确认产物目录
ls -lah dist
```

### 10.5 配置 Nginx（前端静态 + 后端 API 反代）

创建配置文件：

```bash
sudo vim /etc/nginx/conf.d/edu-live.conf
```

示例配置（请替换域名与证书路径）：

```nginx
server {
	listen 80;
	server_name 你的域名.com;

	root /opt/edu-live/edu-live-bbb-full/edu-live-admin/dist;
	index index.html;

	location / {
		try_files $uri $uri/ /index.html;
	}

	location /api/ {
		proxy_pass http://127.0.0.1:8080;
		proxy_http_version 1.1;
		proxy_set_header Host $host;
		proxy_set_header X-Real-IP $remote_addr;
		proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
		proxy_set_header X-Forwarded-Proto $scheme;
	}
}
```

应用配置：

```bash
sudo nginx -t
sudo systemctl enable nginx
sudo systemctl restart nginx
```

### 10.6 配置 HTTPS（Certbot）

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名.com
sudo certbot renew --dry-run
```

### 10.7 首次上线验收

```bash

pm2 status

# 2) 查看后端日志
```

- 按“八、BBB 联调验收清单”逐项完成验证。

### 10.9 快速回滚（保留上一版本）

建议每次发布前做快照目录：

```bash
cd /opt/edu-live
cp -a edu-live-bbb-full edu-live-bbb-full.bak.$(date +%F-%H%M)
```

回滚时：

```bash
cd /opt/edu-live
mv edu-live-bbb-full edu-live-bbb-full.failed.$(date +%F-%H%M)
mv edu-live-bbb-full.bak.2026-07-06-1200 edu-live-bbb-full

cd /opt/edu-live/edu-live-bbb-full/edu-live-server
pm2 restart ecosystem.config.js --env production

sudo systemctl reload nginx
```
